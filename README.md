# Vibo Solutions — Animated Social Reels

*A set of vertical social-media reel posts built in **pure HTML & CSS** — brand-styled motion graphics for the Vibo Solutions brand, hand-coded with no video editor.*

**What this project demonstrates:** branded content production · visual & motion design · marketing creative · respect for a brand system (typography, color, pacing, timing).

---

## What's inside

A series of self-contained animated reel pages (office, kitchen, house, cities, and basement themes). Each one is a single HTML file that runs a short, looping motion sequence:

- Logo reveal with timed entrance
- A gold accent system (`#c89b3c`) over a deep navy stage
- Editorial typography (Playfair Display + Montserrat)
- Timed image slideshows with brightness/contrast grading and a film-grain overlay
- All animation driven by CSS keyframes — no video, no external libraries

## How to view

Open any `reel-*.html` file in a web browser. Each plays its animation on load.

## Tech

`HTML` · `CSS animations / keyframes` · `responsive vertical (9:16) layout`
